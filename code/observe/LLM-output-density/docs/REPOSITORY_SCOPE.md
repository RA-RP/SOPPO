# Repository Scope

## Included

- Current source code, including untracked-but-current Cycle 09 scripts from the working tree.
- Configuration files, registry schemas, tests, and protocol documentation.
- The research fact/claim workspace needed for continued paper development.
- Chinese and English LaTeX sources, supplementary material, bibliography, and vector figures.
- A compact selection of derived numeric artifacts and formal manifests.

## Excluded

- Existing Git history from the original repository.
- Model weights, LoRA checkpoints, rollout caches, and activation caches.
- Raw or per-token spectrum dumps and large sample-level outputs.
- Copyrighted paper PDFs and literature-summary PDFs.
- Submission ZIPs, LaTeX build products, runtime outputs, and caches.

The original local workspace remains the archive of record for excluded artifacts. This
clean repository is the transportable research and paper workspace.
