## R6-2 — 主角谱与转动方向的 σ 排名（"转到哪里"的直接检验）【零 GPU】

**动机**：θ_mean ≈ 0.2° 而 θ_max ≈ 19° ⇒ **重定向是稀疏的**：1011 个功能方向中绝大多数纹丝不动，
只有极少数大幅转动。若两臂转动总量相当（R6-1 若确认），则差异必在**转了哪些方向**。

**任务**（全部从现有 UV artifact 计算）：
1. **主角谱**：对每格输出全部 r_ε 个主角 θ₁…θ_r（现在只报了 max/mean）。
   量化稀疏度：转动 >1° / >5° 的方向数占比。
2. **转动方向的 base-σ 排名**：对转动最大的 top-k 个方向，查它们在 **base 谱**里的排名。
   → 转的是**核心方向**（σ 大）还是**边缘方向**（σ 小）？
3. **两臂转动方向的重叠度**：两臂的"大转动方向集合"是否重合。

**预注册假设（写在结果之前）**：
> **H-where**：在等量移动与等量转动下，OPD 重定向的是**功能核心方向**（base 谱高 σ 段），
> SFT 重定向的是**边缘方向**（低 σ 段）——这解释了为何同样的转动，OPD 换来功能集约（r_ε −24）、
> SFT 换不到（−6）。

**裁决树**：
- OPD 的大转动方向 σ 排名显著靠前、SFT 靠后 → H-where 成立，得到机制陈述（完全在压缩框架内、有控制变量）
- 两臂 σ 排名无差异 → H-where 证伪；"转到哪里"需另找观测量
- 两臂转的是同一批方向但落点不同 → 需要落点侧的新指标（转向后的 σ？）
