## 本轮定位（论点已收束，2026-07-14）

论文论点收束为一句话：

> **我们在白化激活空间——其谱尾直接量化"压缩到 r 维所损失的输出精度"——比较匹配的 OPD 与 SFT 轨迹，发现二者以相当的函数移动量换来截然不同的功能可压缩性：OPD 持续大幅提升，SFT 几乎不变；且这一可压缩性的起伏与 ID 能力的 dip–recover 同步。**

由此论文是**双线**结构，Round 5 分别补齐两线的缺口：

- **线 A（结果线）**：压缩的**程度**（已有 r_ε/tail，强）、**方向**（缺）、**质量**（缺）。
- **线 B（过程线）**：dip 是否是"压缩路径分岔"的结果——**本轮主体，可能是论文唯一的机制解释**。

# 线 A：结果线（全部 CPU / 零 GPU，从现有谱与 UV 计算）

## 术语（避免歧义）

- **M1** = Round-4 定义的压缩程度指标族：`tail_energy(r) = Σ_{i>r}σᵢ²/Σσᵢ²`（截到 r 维的相对输出误差，SVD-LLM 定理）与 **`r_ε = min{r : tail(r) ≤ ε}`**（ε=0.05 为主，0.01 为副）。已算，在 `R4_m1_tail_ec.csv` 的 `r_epsilon_current` 列。
- 以下 A1/A2 的核心改动：**把 γ 和 θ 从"人为选定的 r"改为"该格自己的 r_ε"**。

## A1 — γ_{r_ε}（压缩质量；用户 Cycle 07 原始诉求，至今未跑）

```
γ_{r_ε} = σ_{r_ε} − σ_{r_ε+1}
```
含义：**「最后一个功能所需方向」与「第一个可丢弃方向」之间的间隙**。γ 大 = 功能/冗余界限分明（干净压缩）；γ 小 = 界限模糊（压缩勉强、易被扰动推翻）。

⚠️ **历史问题**：`geometry_metrics.py` 的 `spectral_gap(sigma, k)` 支持任意 k，但**所有运行至今只用过 k=1**——即用户 Cycle 07 批评过的 top-1 gap。本轮必须用 `k = r_ε`。

- 逐格（层 × 模块 × 臂 × ckpt × 探针）用**各自的 r_ε**，不得用全局平均。
- 并报 **k=64 固定版本**作稳健性对照（若结论一致，说明不依赖 r 的选法）。
- 输出：`R5_gamma_reps.csv`。

## A2 — θ_{r_ε}（压缩方向）

算法（Björck–Golub 主夹角，与现有 θ_w 实现同）：
```
1. 该格查 M1 的 r_ε（ε=0.05）              例：L18/down_proj/OPD/step40 → r_ε=137
2. base 白化矩阵 M₀=W₀S₀ 的 SVD → U₀,V₀；ckpt t 的 M_t=W_tS_t → U_t,V_t
3. 取前 r_ε 列：U₀,ᵣ 与 U_t,ᵣ（d×r_ε 正交基）
4. C = U₀,ᵣᵀ·U_t,ᵣ  → 对 C 做 SVD → 奇异值 = cos θ₁…cos θ_{r_ε}
5. θ_{r_ε} = arccos(最小奇异值)  ← 最大主夹角；同时报 mean 角
6. V 侧同理（右奇异向量）
```
- 与 A1 同样：逐格用各自 r_ε；并报固定 r=64 对照。
- 输出：`R5_theta_reps.csv`。

## A3 — e_keep 失效诊断

M3 的 `e_keep_U/V` 两臂全程 ≈1.0000（饱和、无判别力）。定量说明其为**构造性**结果：LoRA 更新范数极小（ρ²≈0.02、θ_w canonical cos²≥0.99），由 Davis–Kahan 上界 sinΘ ≤ ‖ΔW‖/γ 钳制 ⇒ e_keep≈1 近乎必然。
- 报告 ‖ΔW‖_F 的实际量级（逐层逐模块）与该上界的对照。
- 输出：`R5_ekeep_diagnosis.md`（+ 支撑 CSV）。这条进论文的 limitation。

## A4 — 样本级 bootstrap（统计地基，**必做**）

现有 M1/M2 与 A1/A2 全是点估计。以下是论点的承重梁，**必须有 CI**：
1. **r_ε 的两臂差**（E 型探针终点：OPD −24.3 vs SFT −6.4）；
2. **M2 的"等量移动"**（OPD 0.0152 vs SFT 0.0131）——这是"脱钩律"的关键，需检验两臂是否**统计上相当**；
3. γ_{r_ε}、θ_{r_ε} 的两臂差。
- bootstrap 单元 = **样本**（窗嵌套其内，沿用 v2 规格）；draws 256 起。
- 输出：`R5_bootstrap_ci.csv`。

## A6（清理）— raw ER 修复

现实现得到 raw ER ≈ **1.1–3.8**，而 2605.30524 原文（§3.1 + Fig 2）报的是**归一化 ER 0.60–0.75**（即 2560 维里约 1500–1900 个有效方向）。**我们相差三个量级 ⇒ 根本没有复现他们的构念**，此前"raw 静默"的结论是被量纲误导的（其相对变化 3–10% 其实大于白化的 1.2%）。
- 诊断：报告 raw 协方差前 5 个特征值的能量占比（验证 outlier 维度主导假设）。

- 参考锚：我们的 anisotropy 复现（centered mean pairwise cosine 0.12–0.20）与其 Fig 2（0.08–0.15）**量级吻合** → anisotropy 侧对了，问题定位在 ER 侧。
- 输出：`R5_raw_er_fixed.csv` + 诊断说明。

# 线 B：过程线 —— dip 是否是"压缩路径分岔"（本轮主体，需 GPU）

## 理论（用户提出，2026-07-14）

静态探针把输入分布**固定住**，恰好抹掉了 dip 的成因；dip 本质上是一个**关于分布关系**的现象：

> SFT 的损失定义在**外部静态分布**（数据集 CoT）上，但模型实际输出分布在漂移。当它开始模仿新格式却尚未内化时，"**被优化的分布**"与"**它实际生成的分布**"之间出现裂口——**dip 就是这个裂口达到峰值的时刻**。OPD 的损失定义在自己的 rollout 上（on-policy），两个分布天然锁在一起，裂口不出现——所以它没有（或只有极小的）dip。

这是 **exposure bias 的几何版本**。关键测量洞察：**在同一 checkpoint 内比较静态与动态探针，权重是同一个 ⇒ 权重项被消掉，剩下的纯粹是分布错配**。

## B1 — 补 SFT 训练域自生成（**推翻 round-4 决定，用户已确认**）

Round-4 曾裁定"SFT 的 H 不含 math"（当时 H 的语义是"非训练域的自我声音"，SFT 的 math 自生成属杂交类别）。**新理论下它是最关键的一格**：SFT 在训练域上"**自己会怎么解题**" vs "**数据集是怎么解的**"——这个差距就是 exposure bias 本身。

- 生成：**两臂 × 7 ckpt × math 域**的自生成（OPD 侧已有 = 其 rollout；**SFT 侧需新生成**）。
- ≥3 生成种子批；参数冻结、入 manifest；沿用 v2 生成配置（temp 0.6 / top_p 0.9）。
- 输出：语料 + `R5_selfgen_manifest.json`。

## B2 — 交叉矩阵探针（**全 7×7，不裁剪，用户已确认**）

用 checkpoint **i 的权重**测 checkpoint **j 的文本**：

```
            文本来源 →
权重 ↓    X_0   X_5   X_10  X_20  X_40  X_160  X_624
W_0       ·     ·     ·     ·     ·     ·      ·
W_5       ·    [◆]    ·     ·     ·     ·      ·
W_10      ·     ·    [◆]    ·     ·     ·      ·
W_20      ·     ·     ·    [◆]    ·     ·      ·
W_40      ·     ·     ·     ·    [◆]    ·      ·
W_160     ·     ·     ·     ·     ·    [◆]     ·
W_624     ·     ·     ·     ·     ·     ·     [◆]
          ↑第一列 = 静态（纯权重效应）      ◆对角 = 实际工作状态
```

- **第一列**（固定 base 文本，变权重）= 纯权重效应 = 现有静态测量；
- **对角线**（各自文本 + 各自权重）= 模型的**实际工作状态**；
- **行内变化**（固定权重，变文本）= **纯文本效应** —— 这一格是免费得到的控制变量，**它一次性解决了此前砍掉动态探针的唯一理由（双动混淆）**；
- 全矩阵 = 7×7 = 49 格 × 两臂 × 层 {9,18,27} × 7 模块。
- 窗口/归一化/bootstrap 全部沿用 **v2 规格**（生成区内随机窗 k=3、层级归一化、样本级 bootstrap）。
- 输出：`R5_cross_matrix.csv`（含每格的 ER / r_ε / tail / γ / θ）。

## B3 — Mismatch 指标

```
Mismatch(t) = r_ε( W_t , 自己的输出 X_t )  −  r_ε( W_t , 静态参考 X_0 )
```
同 ckpt 内比较 ⇒ 权重项消掉 ⇒ 纯**分布错配度**（模型处理"自己的声音" vs "外部固定参考"的功能维度差）。
- 同时报 tail_energy 版本的 Mismatch（固定 r=32/64）。
- 输出：`R5_mismatch.csv` + 轨迹图数据。

## B4 — 预注册预测（**结果出来前写死，不得事后修改**）

```
H-mismatch:
  (1) SFT 的 Mismatch(t) 在 step 20（其 ID dip 步）达到峰值，recover 时回落；
  (2) OPD 的 Mismatch(t) 全程平坦且显著小于 SFT 的峰值。

裁决：
  两条都成立      → dip 的"分布错配/压缩路径分岔"机制成立（论文的机制解释）
  仅 (1) 成立     → 机制对 SFT 成立，OPD 侧另有原因（需 off-KD 拆分）
  (1) 不成立      → 假设证伪，Mismatch 与 dip 无关，如实记录并退回相关性叙事
```
coder **不做裁决**，只报读数与上述三分支的对应关系。
